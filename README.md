# GP_5_Team_15
**Бизнес-задача 1. Оценить эффективность текстовой подачи продукта до запуска для повышения охватов**

Построить модель, которая по описанию продукта определяет, насколько текстовая карточка похожа на карточки успешных запусков Product Hunt. Результатом модели становится текстовый скоринг продукта, который можно использовать как отдельный показатель готовности страницы к запуску, так и для более подробного предсказания

**Бизнес-задача 2. Предсказать вероятность получения высокого охвата проекта после запуска по его профилю**

Построить модель, которая по данным проекта из Product Hunt API и текстовому скорингу из первой задачи оценивает вероятность высокого результата запуска: большого числа голосов, комментариев или попадания в верхние позиции дневного/недельного/месячного рейтинга.
